# **Summary**

Configure Book deployments to use destinations determined by `main`, `develop`, and the release version, with `main` always representing the latest version.

# **Acceptance Criteria**

- [ ] Book deployments from `main`, `develop`, and versioned releases resolve to their intended destinations.
- [ ] The `main` deployment and the latest versioned deployment always represent the same Book content.
- [ ] Different versioned deployments remain addressable by their version.
