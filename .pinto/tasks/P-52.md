# **Summary**

Automate dependency and GitHub Actions maintenance so security and compatibility updates are proposed, reviewable, and protected against untracked drift.

# **Acceptance Criteria**

- [ ] Every GitHub Actions reference is pinned to a full commit SHA and retains a human-readable version comment.
- [ ] Scheduled automation proposes updates for Cargo dependencies and GitHub Actions.
- [ ] The deprecated test-only YAML dependency is replaced with a maintained parser or covered by an explicit, reviewed compatibility decision.
- [ ] The dependency policy records approved duplicate versions and detects newly introduced duplicates.
- [ ] Maintainer documentation explains how to review and validate automated update proposals.
