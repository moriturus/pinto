# **Summary**

Make deep parent/child and dependency traversals safe for large or malformed boards, preventing stack overflows while preserving deterministic output and diagnostics.

# **Acceptance Criteria**

- [ ] Hierarchical ordering, Kanban row layout, dependency-cycle inspection, and point aggregation handle synthetic chains several thousand levels deep without a stack overflow.
- [ ] Traversal behavior remains deterministic and does not drop items or hide cycles when the input is malformed.
- [ ] The implementation uses bounded, actionable failure behavior for depth or resource exhaustion when complete traversal is not possible.
- [ ] Regression tests cover deep parent chains, deep dependency chains, and cyclic inputs through the relevant service and CLI paths.
