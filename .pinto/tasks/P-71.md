# **Summary**

Include Sprint Retro and Review child records in machine-readable output and board interchange so the new Sprint hierarchy remains complete, portable, and Git-friendly across supported storage backends.

# **Scope**

- Extend child-record JSON output with the Sprint-matching IDs, parent Sprint reference, state, timestamps, and Markdown body.
- Include Retro and Review records in complete `export --json` snapshots and restore them through `import`.
- Preserve the records through supported storage migration and Git-backed mutation boundaries.
- Keep snapshots from boards without child records backward-compatible.

# **Acceptance Criteria**

- [ ] Retro and Review show/list JSON output contains their parent Sprint reference and complete persisted record data.
- [ ] `export --json` includes existing Retro and Review records, and `import` restores them without changing their IDs or parent links.
- [ ] File, Git, and optional SQLite storage paths preserve the one-per-Sprint child records through their supported migration or persistence boundaries.
- [ ] A board snapshot without Retro or Review records remains valid and imports as before.
- [ ] Plain-text records and their JSON representation remain consistent and reviewable through Git.
