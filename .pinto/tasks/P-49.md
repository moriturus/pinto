# **Summary**

Add a PBI splitting feature that is available in Kanban mode and creates new PBIs from an existing item, with optional dependency or parent-child relationships. Copy the source body by default, while allowing the caller to choose an empty body, a template body, or an explicitly supplied body.

# **Acceptance Criteria**

- [ ] An existing PBI can be split into one or more new PBIs.
- [ ] Kanban mode exposes PBI splitting and applies the selected relationship and body options.
- [ ] The split operation can optionally create dependency relationships for the resulting PBIs.
- [ ] The split operation can optionally create parent-child relationships between the source and resulting PBIs.
- [ ] New PBI bodies copy the source body by default.
- [ ] The split operation supports selecting an empty body, a template body, or an explicitly supplied body.
