# **Summary**

Make release instructions reusable for every release by removing fixed historical version values and adding a checked pre-tag workflow.

# **Acceptance Criteria**

- [ ] Generic release instructions use an explicit version placeholder or a command-derived value instead of a fixed published version.
- [ ] The documented pre-tag workflow verifies package versions, committed lockfiles, changelog entries, installation examples, and tag availability.
- [ ] Documentation regression tests detect accidental reintroduction of fixed historical release values in the generic procedure.
- [ ] The resulting command sequence remains clear and executable for a maintainer preparing a new release.
