# **Summary**

Create GitHub Releases automatically from the repository's `CHANGELOG` so tagged releases can be published without manually creating the release entry.

# **Acceptance Criteria**

- [ ] A release tag automatically creates the corresponding GitHub Release.
- [ ] The generated GitHub Release notes are sourced from the matching `CHANGELOG` entry.
- [ ] The release workflow does not require manual GitHub Release creation.
