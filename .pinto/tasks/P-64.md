# **Summary**

Allow authors to escape literal `automate` output-placeholder syntax when it must be passed as text, especially in non-item-ID arguments such as `--body`.

# **Acceptance Criteria**

- [ ] `automate` supports an explicit escape form for literal output-placeholder text in non-item-ID arguments.
- [ ] Escaped placeholder text reaches the child command literally, while unescaped supported item-ID references continue to resolve normally.
- [ ] Dry-run and apply regression tests cover escaped literal placeholder text in multiline `--body` values and preserve actionable diagnostics for invalid item-ID placeholders.
