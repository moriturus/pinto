## Summary

Add split to the help menu displayed while Kanban mode is active.

## Implementation Approach

The Kanban help overlay is built by `help_lines()` in
`src/cli/kanban/runtime/render.rs`, which collects key hints for a fixed set of
`KeyAction`s and renders them through the `kanban-help-entries` Fluent message.
The `Split` action (`KeyAction::Split`, default key `s`) is already dispatched
by the runtime but is absent from this overlay.

- Add the `Split` key to `help_lines()`: resolve its hint, include it in the
  width-padding set, pad it, and pass it to the localizer as `split`.
- Add a `{$split}: split item` line to `kanban-help-entries` in both
  `locales/en-US.ftl` and `locales/ja-JP.ftl`, positioned with the other
  item-mutating operations (after `edit`).
- TDD: a unit test asserts `help_lines` lists the split entry with its key, and
  a PTY integration test opens the help overlay (`?`) and confirms that `split`
  appears in the rendered menu.

## Acceptance Criteria

- [x] The help menu shown in Kanban mode includes split.
